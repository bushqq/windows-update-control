# Windows 自动更新关闭与恢复脚本

为一台 **Windows 11 家庭中文版 25H2（内部版本 26200）** 电脑制作的 PowerShell 脚本。脚本会检查系统版本及版本类型；不匹配时停止执行。没有在其他 Windows 版本上验证。

## 使用

下载仓库文件，放在同一个文件夹内。双击 `DisableUpdates.cmd`，在管理员授权窗口选择“是”。需要恢复时，双击 `RestoreUpdates.cmd`。如提示更新服务尚未停止，重启电脑后生效。

关闭前会将原配置保存到 `C:\ProgramData\WindowsUpdateControl\original-settings.json`。不要删除该文件；恢复脚本需要它。重复运行关闭脚本不会覆盖首次备份。恢复成功后会删除备份。

## 改动范围

- 禁用 Windows Update 服务 `wuauserv`，尝试停止该服务。
- 尝试禁用更新协调服务 `UsoSvc`。若被系统保护拒绝，会显示提示。
- 设置 `NoAutoUpdate=1` 作为辅助策略。
- 不更改 BITS 服务、Defender、防火墙或系统文件权限。

关闭期间，安全补丁、通过 Windows 更新获取的驱动以及手动检查更新会受影响。大型系统升级或系统自修复可能重新开启更新，无法保证永久关闭。若系统正在安装更新，先等安装完成再运行脚本。

制作时只检查了脚本语法和目标电脑的只读状态；未实际运行关闭或恢复操作。
